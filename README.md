## 🌟 Key Features

- **⚡ 4K Live Particle Background**: High-performance HTML5 Canvas rendering interactive glowing neon particle connections.
- **💎 Premium Glassmorphism & 3D Tilt Cards**: 3D perspective tilt effect on interactive showcase cards powered by Vanilla Tilt.
- **🎥 AI Anime & Project Video Animations**: Custom 10-second seamless MP4 & WebM video loops (`H.264 yuv420p` + `VP9`) for high-definition visual impact.
- **🤖 Generative AI & Vibe Coding Section**: Highlighting serverless browser compilers, Pyodide WebAssembly execution, and prompt engineering at Antigravity.
- **🔊 AI Voice Greeting Engine**: Automated Web Speech Synthesis & Web Audio greeting with an interactive top banner playback toggle.
- **📄 Recruiter-Ready ATS Vector Resume**: Includes a single-page downloadable vector PDF (`Shaik_Harun_Resume.pdf`) and an interactive full-screen preview modal.
- **📱 Universal Responsive Design**: Flawlessly optimized across all device breakpoints (Desktop, Laptop, Linux, Android, and iOS).

## 🚀 Local Development Setup

To run this website locally on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/SHAIK-HARUN/portfolio.git
   cd portfolio
   ```

2. **Start a local HTTP server**:
   ```bash
   python -m http.server 8085
   ```

3. **Open in browser**:
   Navigate to `http://localhost:8085` in your favorite web browser.
